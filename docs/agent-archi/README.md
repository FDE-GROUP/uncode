# AI Agent 架构治理系列

## 定位

本系列是关于 **AI Agent 系统架构治理** 的理论与实践指南。核心命题：

> **领域是第一公民，认知显化与决策驱动是服务于领域的两条路径，本体是运行在路径上的语义轮子。**

与旧版 `docs/ai-agent-archi/` 系列的关系：本系列是在范式收敛（领域第一公民 → 路径-轮子框架）后从零重写的版本。旧系列保留在 `docs/ai-agent-archi/` 作为历史参考。新系列完全独立，结构更清晰，立场更一致。

## 核心公式

```
LLM 负责认知与生成，系统架构负责决策与治理。
领域是第一公民，本体是领域的形式化表达。
认知显化是将 LLM 概率输出转化为结构化认知的路径。
决策驱动是从结构化认知到确定性行动的治理闭环。
语义防火墙是连接认知路径与决策路径的三层管线。
```

## 术语约定

本系列使用以下术语体系：

| 术语 | 含义 | 与旧系列的区别 |
|:---|:---|:---|
| 第一公民 | 领域 | 旧系列曾经历"决策→两类三种→领域"的迭代 |
| 认知显化 | 从 LLM 概率输出到结构化认知的路径 | 不变 |
| 决策驱动 | 从认知到行动的治理闭环 | 不变 |
| 语义轮子 | 本体作为运行在路径上的语义基础设施 | 旧系列曾误将本体作为第一公民之一 |
| 语义防火墙 | P→V→N 三层管线 | 不变 |
