# 范式总论：认知显化与决策驱动设计

## 核心命题

**认知显化与决策驱动设计**（Cognition-Explicitization & Decision-Driven Design）是一个面向 AI Agent 系统的架构治理范式。它的核心命题是：

> **领域是第一公民。认知显化和决策驱动是服务于领域的两条路径。本体是运行在这些路径上的语义轮子。**

## 范式根源

本范式从以下思想中汲取养分：

| 来源 | 贡献 | 与本范式的关系 |
|:---|:---|:---|
| **领域驱动设计**（DDD） | "领域"是系统的核心关注点 | 领域第一公民直接继承 DDD |
| **认知科学** | "认知"是 Agent 作为智能系统的核心过程 | 认知显化路径的理论基础 |
| **系统治理** | 系统架构负责决策，LLM 负责生成 | 决策驱动路径的理论基础 |
| **本体工程**（Palantir OMS） | 形式化的语义基础设施约束 Agent 的认知空间 | 本体的设计参照 |

## 四层架构

```
┌──────────────────────────────────────────────────┐
│                  领域（第一公民）                   │
│        ┌─────────────────────────────┐            │
│        │         认知层               │            │
│        │  LLM 可能性空间              │            │
│        │  上下文构建·提示词管理        │            │
│        │  不确定性管理                │            │
│        └──────────┬──────────────────┘            │
│                   │ 概率输出                       │
│        ┌──────────▼──────────────────┐            │
│        │      语义防火墙              │            │
│        │  Parsing → Validation       │            │
│        │  → Normalization            │            │
│        └──────────┬──────────────────┘            │
│                   │ 确定性提案                     │
│        ┌──────────▼──────────────────┐            │
│        │         决策层               │            │
│        │  提案接收·裁决·执行·审计     │            │
│        └──────────┬──────────────────┘            │
│                   │ 事件流                         │
│        ┌──────────▼──────────────────┐            │
│        │         治理层               │            │
│        │  编排·工具·记忆·观测·进化    │            │
│        └─────────────────────────────┘            │
│                                                    │
│  本体 = 路径上运转的语义轮子                        │
│  （类型注册表、约束公理、Action 元数据）             │
└──────────────────────────────────────────────────┘
```

## 核心公式

```
LLM 负责认知与生成   +   系统架构负责决策与治理
         ↓                        ↓
     概率可能性               确定性约束
         ↓                        ↓
     认知显化路径             决策驱动路径
         ↓                        ↓
     本体轮子确保两条路径运行在一致的语义轨道上
```

## 范式承诺

采用本范式的系统承诺以下原则：

1. **领域优先**：任何架构决策都应从领域出发，而非从技术或模型出发
2. **认知显化**：LLM 的认知过程应被显式建模，而非隐式假设
3. **决策分离**：生成与决策是不同性质的职责，应由不同组件承担
4. **防火墙隔离**：认知层与决策层之间必须有语义防火墙，防止概率泄漏
5. **本体约束**：所有跨层通信必须经过本体校验，确保语义一致性
6. **治理闭环**：每个决策必须可追踪、可审计、可回滚

## 何时适用此范式

本范式适用于以下场景：
- AI Agent 系统涉及多轮人机协作
- 系统需要处理不确定的 LLM 输出并产生确定性行动
- 系统的核心价值在于领域知识而非模型能力
- 需要跨 Agent 协作的复杂场景
- 对可审计性和可解释性有要求的场景

本范式**不适用**于：
- 单次调用的简单文本生成
- 完全由 LLM 自主决定的端到端应用
- 无须领域约束的原型实验
