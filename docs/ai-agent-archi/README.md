## 核心论点（贯穿五篇）

1. **DDD 没有死，它在进化**——战略 DDD（限界上下文、上下文映射、通用语言）在 AI Agent 时代更加重要；战术 DDD（聚合、实体、值对象）需要重建。

2. **认知与决策必须分离**——LLM 负责认知（生成可能性），系统负责决策（约束可能性）。语义防火墙是两者之间的唯一握手协议。

3. **事件流是双向桥梁**——事件不仅是"发生了什么"，更是认知层 → 决策层 → 认知层的完整闭环，同时服务于在线推理和离线优化。

4. **治理是多层的**——范式层定义"怎么分"（认知与决策驱动设计），治理层定义"怎么跑"（7 种运行时范式），两者正交但互补。

## 各篇的独特贡献

- **①** 建立了 DDD 在 AI 时代不适配的**完整分析框架**（四重冲突），并提出了所有后续讨论的基础概念（语义防火墙、决策边界、事件溯源升级）
- **②** 用**可传播的语言**重写了同一论证，让非 DDD 背景的读者也能理解
- **③** 补充了 DDD 之外的**操作面工具**，其中"铁三角"（事件驱动 + 事件溯源 + 约束设计）后来被证明是治理的"最小可行集合"
- **④** 用真实项目验证了理论的**可落地性**，同时暴露了 CDD 的定位模糊和决策层建模缺口——直接推动了⑤的范式升级
- **⑤** 将前四篇的碎片**收口为完整范式**：认知与决策驱动设计 + 综合治理 = AI Agent 系统开发的完整方法论
